# Teamwork Shooter Game
This is teamwork shooter game. You must teamwork with your friends to win this game.
Game Function:
General:
Key M: Mute the game sound.
Key U: Unmute the game sound.
Player 1 Control:
Key Space - Fire the bullet to enemy in player 1 rocket.
Key Left Arrow - Move player 1 rocket to left.
Key Right Arrow - Move player 1 rocket to right.
Player 2 Control:
Key F - Fire the bullet to enemy in player 2 rocket.
Key A - Move player 2 rocket to left.
Key D - Move player 2 rocket to right.
Win and Lose conditional:
The game will win if player 1 and 2 teamwork and the score is 10 without 3 missed enemy.
The game will lose if the life (the change coloring text in top right) is 0 or the enemy missed 3 times.
General Game Knowledge:
The player 1 can't go to the player 2 coloumn, with the opposite conditional on player 2.
The game will always automatically restart either win or lose until you press the close button at the top right of the window.
